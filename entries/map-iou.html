01一句話重點

IoU 用「兩個框重疊的比例」判斷一次偵測算不算對；再依信心分數排序畫出 Precision–Recall 曲線，曲線下面積就是 AP，所有類別 AP 的平均就是 mAP。

02核心概念

為什麼需要它？偵測模型輸出的是框，不是單純的對或錯。我們需要一個規則判斷「這個預測框算不算找到車牌」，也需要一個數字總結模型在各種信心門檻下的整體表現，才能公平比較不同模型與不同天候。

IoU (Intersection over Union)：預測框與真實框 (ground truth) 的交集面積除以聯集面積，介於 0~1。IoU 大於門檻（常用 0.5）就算真陽性 (TP)，否則是假陽性 (FP)；沒被找到的真實框則是假陰性 (FN)。

AP 與 mAP：把所有預測框依信心分數由高到低排序，逐一計算 Precision 與 Recall，畫出 PR 曲線，曲線下面積為該類別的平均精確度 (Average Precision, AP)。多個類別的 AP 取平均就是 mAP。

兩種常見寫法：mAP@0.5 表示 IoU 門檻固定 0.5（PASCAL VOC 習慣）；mAP@0.5:0.95 則在 0.5 到 0.95、每 0.05 一個門檻，共 10 個門檻上取平均（COCO 習慣），對框的精準度要求更嚴格。

04重點整理

IoU = |A ∩ B| / |A ∪ B|

A：預測框；B：真實框。完全重合為 1，完全不重疊為 0。

Precision = TP / (TP + FP)，　Recall = TP / (TP + FN)

Precision：框出來的有多少是對的；Recall：該找到的車牌找到了多少。

AP = ∫01 p(r) dr，　mAP = (1/N) Σi=1N APi

p(r)：Recall 為 r 時的 Precision；N：類別數。若只有 plate 一類，mAP 就等於 AP。

車牌辨識正確率 = 整串號碼完全正確的車牌數 / 車牌總數

第二階段字元辨識常用的指標：只要錯一個字元就算整張錯。

05與我的論文的關係

用在哪裡

第四章實驗結果的主要指標。建議論文同時報告：偵測的 mAP@0.5 與 mAP@0.5:0.95、整串車牌辨識正確率，以及推論速度 FPS（附上硬體規格）。

要注意什麼

  • 依天候分組報告：把晴天、雨天、霧、夜間各自的 mAP 做成表格，才能凸顯惡劣環境的研究重點。
  • 和其他論文比較：先確認對方用的是哪一種 mAP、哪個資料集、哪種切分方式，條件不同的數字不能直接比較。

06常見問題與注意事項

  • 混用 mAP 定義：mAP@0.5 通常遠高於 mAP@0.5:0.95，表格中務必標明。
  • 小物件對 IoU 很敏感：車牌只有幾十個像素時，框偏移幾個像素 IoU 就會大幅下降。
  • 字元正確率 ≠ 車牌正確率：字元層級 95% 正確，整串車牌正確率可能低很多。
  • FPS 沒寫硬體：同一模型在不同 GPU 上的速度差很多，沒有硬體規格的 FPS 沒有參考價值。
