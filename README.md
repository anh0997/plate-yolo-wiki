# YOLO 車牌辨識知識庫 Plate-YOLO Wiki

碩士論文「以 YOLO 進行惡劣環境下之車牌辨識（台灣／越南交通）」的研究知識庫。
把讀過的論文、資料集、概念與評估方法整理成格式一致的知識條目，每個條目都標註對應的論文章節。

- 網站：https://anh0997.github.io/plate-yolo-wiki/
- AI 開發規則：[AGENTS.md](./AGENTS.md)

## 如何新增條目

依 `AGENTS.md` 第 8 節：在 `assets/entries.js` 末端加一筆資料，複製 `entries/_template.html` 填寫 8 個區塊，首頁會自動更新。
也可以直接對 AI 說：「依照 AGENTS.md 新增一個條目：CCPD 資料集」。

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何東西。
